# Changelog

## 1.5.0

### Added

- **Unread only** is now a third catalogue filter alongside **All books** and **Favourites only**. It uses the existing reading status, regardless of whether all pages have been collected.
- **Optional Spoken Readables integration:** A **Play** button appears next to **Favourite** when Spoken Readables is enabled and an installed audio pack has a recording for the displayed page. Playback starts on that page and follows Spoken's settings for subsequent pages.
